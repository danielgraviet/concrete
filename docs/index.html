Open it on a new Mac

Early builds are unsigned, so Chrome and macOS may warn that the file is unsafe or “damaged.” That is expected until we notarize with Apple.

  1. In Chrome: click the download ↑ arrow → Keep / Download anyway if it blocks the DMG.
  2. Open the DMG and drag Concrete into Applications.
  3. If macOS says the app is damaged or should be deleted, clear the quarantine flag in Terminal:
    xattr -cr /Applications/Concrete.app
  4. Then open Concrete normally (or right-click → Open).
  5. Still blocked? System Settings → Privacy & Security → Open Anyway.
